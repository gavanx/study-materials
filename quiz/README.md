# 每日一题

把整卷试卷拆成单题，每天按日期随机抽一题。纯静态页，手机/平板打开即用，无需后端。

## 功能

- **每日一题**：题库用固定种子洗一次序，按天往后走——同一天在任何设备打开都是同一道，且一轮（308 天）内不重复；`?date=2026-10-24` 可覆盖日期便于测试
- **判分**：选择题点选项立即判对错；填空题对答案后由孩子自评「算对了 / 算错了」
- **知识点**：按 36 届 WMO 五年级初测考试大纲标记（计算 / 应用题 / 几何图形 / 计数 / 组合，超纲内容另设数论、其他板块），题卡上直接显示
- **解析**：判完自动展开，带知识点标签
- **错题本 / 收藏**：做错的自动收录，可重做
- **打卡**：当天完成「今日题」记一次，连续天数按自然日回溯；「换一题」属于加练，不计入打卡

数据存在浏览器 `localStorage`（`quiz_progress` / `quiz_wrong` / `quiz_fav`），按域名隔离，换设备或清缓存不会同步。

## 加新卷子

1. 在 `tools/manifest/` 下按现有格式新建一份：每页给出题目 `y` 区间（占页高比例），
   双栏/横版卷子再加 `x`；跨栏或跨页的题目用 `parts` 把几段裁图拼起来
2. `python3 quiz/tools/crop.py` —— 裁图、生成 `data/questions.json` 与 `tools/contact-sheet.html`
3. `python3 quiz/tools/montage.py <setId> /tmp/m.webp` 拼成校对图，逐张看有没有缺选项、裁到上一题
4. `python3 quiz/tools/qa_crops.py <setId>` —— OCR 质检，重点看「疑似裁进了答案/解析」
5. `python3 quiz/tools/validate.py` —— 结构校验（id 唯一、答案在选项里、页图存在）
6. 本地起服务验证：`python3 -m http.server 8000` → `http://localhost:8000/quiz/`

### manifest 字段

| 字段 | 说明 |
|------|------|
| `kind` | `choice` 单选 / `fill` 填空与解答 / `stem` 组合题公共题干（不进每日一题池） |
| `y` | `[起, 止]`，占页面高度的比例；横向范围默认按墨迹自动收紧 |
| `x` | 可选，限定所属栏，横版双栏卷必填 |
| `parts` | 可选，跨栏/跨页题的多个裁切段，按顺序竖向拼接 |
| `stemId` | 子题指向所属组合题的题干 id |
| `answer` | 选择题为 `A/B/C/D`，填空题为标准答案文本 |
| `needsReview` | 答案存疑时置 `true`，页面显示「答案待核对」 |

### 工具

| 脚本 | 用途 |
|------|------|
| `crop.py` | 按 manifest 裁题图、汇总 questions.json |
| `montage.py` | 把某套卷的裁图拼成一张校对图 |
| `qa_crops.py` | 用 macOS Vision OCR 检查裁图（答案泄漏/题号缺失） |
| `validate.py` | manifest 结构校验 |
| `scan_blocks.py` | 打印页面墨迹块位置，写 manifest 的 y 区间时参考 |
| `pdf_pages.py` | 把 PDF 渲染成 PNG（答案册多为 PDF） |
| `classify.py` | 按考试大纲给每题标板块与知识点，写回 manifest |
