# 每日一题

把整卷试卷拆成单题，每天按日期随机抽一题。纯静态页，手机/平板打开即用，无需后端。

线上地址：https://gavanx.github.io/study-materials/quiz/

## 现在有哪些题

| 卷子 | 题量 | 说明 |
|------|------|------|
| 第34届 WMO 五年级复赛（省测） | 25 题（16 选择 + 9 填空） | 另含 4 段组合题公共题干 |

> 注意：这套卷子的官方答案册与试卷**不是同一版本**（答案册第 1 题选 B，本题实算为 D；第 17/18 题小问数量也不同）。
> 本卷答案全部逐题重算，解析由 AI 撰写；标「答案待核对」的两题（第 11、19-3）建议家长过一眼。

## 功能

- **每日一题**：用本地日期做种子选一道题，同一天在任何设备打开都是同一道；支持 `?date=2026-10-24` 覆盖日期便于测试
- **判分**：选择题点选项立即判对错；填空题对答案后由孩子自评「算对了 / 算错了」
- **解析**：判完自动展开，带知识点标签
- **错题本**：判断错的题自动收录，可重做
- **收藏**：题目右上角 ☆
- **打卡**：当天完成「今日题」记一次，连续天数按自然日回溯；「换一题」属于加练，不计入打卡

数据都存在浏览器本地（`localStorage`），换设备或清缓存不会同步。

## 加新卷子

1. 在 `tools/manifest/` 下按 `wmo-34f5.json` 的格式新建一份（每页给出题目 `y` 区间，横向范围脚本自动收紧）
2. `python3 quiz/tools/crop.py` —— 裁图、生成 `data/questions.json` 与 `tools/contact-sheet.html`
3. 打开 `tools/contact-sheet.html` 逐张校对，有截断就改 manifest 里的 `y` 重跑
4. 本地起服务验证：`python3 -m http.server 8000` → `http://localhost:8000/quiz/`

### manifest 字段

| 字段 | 说明 |
|------|------|
| `kind` | `choice` 单选 / `fill` 填空 / `stem` 组合题公共题干（不进每日一题池） |
| `y` | `[起, 止]`，占页面高度的比例；横向由墨迹自动判定 |
| `stemId` | 子题指向所属组合题的题干 id |
| `answer` | 选择题为 `A/B/C/D`，填空题为标准答案文本 |
| `needsReview` | 答案存疑时置 `true`，页面会显示「答案待核对」 |
