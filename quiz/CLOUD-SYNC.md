# 云同步（腾讯云开发 CloudBase）

默认是**纯本地**模式：打卡、错题本、收藏存在浏览器 `localStorage` 里。
按本文配置后，多台设备（手机 / 平板 / 微信内打开）可以用同一个「家庭口令」共享进度。

前端代码已经写好，位于 `quiz/sync.js`，配置项在 `quiz/config.js`。

## 一、开通环境

1. 登录 [腾讯云开发控制台](https://tcb.cloud.tencent.com/)，创建一个环境（免费体验版即可，1 个环境、每月 3000 资源点）。
2. 记下**环境 ID**（形如 `family-quiz-1a2b3c`）。
3. 在「环境 → 访问控制 / API Key」里拿到 **publishable key**（前端用的公开密钥，可以放在网页里）。

## 二、开两项开关

| 位置 | 设置 |
|------|------|
| 身份验证 → 登录方式 | 开启**匿名登录**（每台设备自动获得一个匿名 uid） |
| 环境配置 → 安全域名 | 添加 `gavanx.github.io`（本地调试再加 `localhost`） |

不配安全域名，网页调用会报「非法来源」。

## 三、建集合

在「数据库」里新建集合 `quiz_events`，安全规则填：

```json
{
  "read": "auth != null",
  "write": "auth != null"
}
```

即：登录（含匿名）即可读写。家庭之间靠「家庭口令」隔离，口令是 10 位随机串，相当于家庭账号密码，**不要公开分享**。

集合字段（由前端自动写入，无需手工建索引）：

| 字段 | 说明 |
|------|------|
| `family` | 家庭口令，查询条件 |
| `kind` | `done`（当日完成）/ `wrong`（做错）/ `fav` / `unfav` |
| `qid` | 题目 id，如 `wmo-34f5-07` |
| `date` | 打卡日期 `YYYY-MM-DD`（kind=done 时有） |
| `ok` | 当天是否做对（kind=done 时有） |
| `ts` | 事件时间戳，合并时按它取最新 |
| `uid` | 匿名用户 id，排查用 |

建议给 `family` 建一个普通索引，数据量大时查询更快。

## 四、填配置

编辑 `quiz/config.js`：

```js
window.QUIZ_CONFIG = {
  cloudbase: {
    envId: 'family-quiz-1a2b3c',
    accessKey: '你的 publishable key',
    region: 'ap-shanghai',
    collection: 'quiz_events'
  }
};
```

提交并合并后，线上即生效。

## 五、使用

1. 第一台设备打开页面 → 右上角 ☁（宽屏在左侧「同步」）→ 显示本机生成的 10 位家庭口令
2. 点「复制」把口令发给孩子/另一台设备
3. 另一台设备打开同一页面 → ☁ → 在「加入已有的家庭」里粘贴口令 → 加入
4. 之后每次做题都会自动上传；打开页面时会自动拉取合并。断网时事件进本地队列，联网后自动补传

## 设计说明

- **本地优先**：所有操作先写 `localStorage`，界面立即响应；云端失败不影响做题
- **事件日志**：每次答题/收藏追加一条事件，而不是覆盖整包，避免两台设备同时操作互相覆盖
- **合并规则**：打卡每天取最早一条；错题按次数累计；收藏取最新一条
- **匿名登录**：不需要用户注册，换设备只需输入家庭口令；清除微信缓存会换一个匿名 uid，但数据靠口令仍然能拉回来

## 排查

| 现象 | 检查 |
|------|------|
| 面板显示「未连接」 | `envId` / `accessKey` 是否填对；安全域名是否加了当前站点域名 |
| 报「非法来源」 | 安全域名没配，或从 `file://` 直接打开 |
| 报权限错误 | 集合安全规则是否为 `auth != null`；匿名登录是否开启 |
| 两台设备数据不一致 | 口令是否一致；点「立即同步」强拉一次 |
