## 二、乘法分配律

**核心思想**：正向——(a + b) × c = a × c + b × c，把"合在一起乘"变成"分开乘再相加"；逆向——a × c + b × c = (a + b) × c，把相同的因数（公因数）提出来"合起来乘"。逆向时，式子末尾若只有一个数，如 88×99 + 88，要想到 88 = 88×1，补上一个"×1"再提取。

::: {.problem-card}
**例 1**：用两种方法计算 (25 + 11) × 4，并比较结果。

## 三、减法与除法的性质

**核心思想**：连减性质——一个数连续减去两个数，等于减去它们的和：a − b − c = a − (b + c)；连除性质——一个数连续除以两个数，等于除以它们的积：a ÷ b ÷ c = a ÷ (b × c)。看到减数或除数能凑整，就"合起来减/除"。

::: {.problem-card}
**例 1**：简便计算：854 − 248 − 152

::: {.answer-card}

## 答案 · 六、竞赛挑战

:::

::: {.answer-card}
**例 2**：25 × 17 + 25 × 81 + 50 = 25 × 17 + 25 × 81 + 25 × 2 = 25 × (17 + 81 + 2) = 25 × 100 = **2500**。

::: {.answer-card}
**例 3**：9 + 99 + 999 + 9999 + 99999 = (10 − 1) + (100 − 1) + (1000 − 1) + (10000 − 1) + (100000 − 1) = 111110 − 5 = **111105**。

:::

::: {.answer-card}
**例 4**：两两分组：(2020 − 2019) + (2018 − 2017) + … + (2 − 1)，每组都是 1。2020 个数分成 2020 ÷ 2 = 1010 组，和 = 1 × 1010 = **1010**。

:::

::: {.answer-card}
**练 1**：37 × 48 + 53 × 37 − 37 = 37 × (48 + 53 − 1) = 37 × 100 = **3700**。

:::

::: {.answer-card}

:::

::: {.answer-card}

:::

::: {.answer-card}
**练 4**：1000 + (999 − 998) + (997 − 996) + … + (3 − 2) + 1。从 999 到 2 共 998 个数，两两一组得 499 个"1"。和 = 1000 + 499 + 1 = **1500**。
