## 一、小数乘整数

**核心思想**：小数乘整数 = 几个这个小数相加。竖式时**末尾对齐**（不是小数点对齐），先按整数乘法算，再看因数里有几位小数，就在积里从右往左数出几位点上小数点。

::: {.problem-card}
**例 1**：0.5 × 3 表示什么？等于多少？

:::

::: {.problem-card}
**例 2**：用竖式计算 2.6 × 4。

:::

::: {.problem-card}
**例 3**：0.35 × 6 的积是几位小数？

:::

::: {.problem-card}
**练 1**：3 × 0.4 表示什么？等于多少？

:::

::: {.problem-card}
**练 2**：用竖式计算 1.7 × 3。

:::

## 二、小数乘小数

**核心思想**：小数乘小数，先按整数乘法算出积，再看**两个因数一共有几位小数**，就在积里从右往左数出几位点上小数点。积的末尾如果有 0，一般要去掉。位数不够时，在前面补 0。

::: {.problem-card}
**例 1**：计算 2.4 × 0.5，积是几位小数？

:::

::: {.problem-card}
**例 2**：计算 0.36 × 0.2。

**核心思想**：积的近似数用四舍五入，看保留位数的后一位。**整数乘法的运算律对小数同样适用**——交换律、结合律、分配律都能用来凑整简算：0.25×4=1、1.25×8=10、0.5×0.5=0.25。

**例 3**：简便计算：0.125 × 4.8

## 四、小数乘法的实际应用

**核心思想**：购物问题里"单价 × 数量 = 总价"。估算时把小数看成接近的整数或整数乘小数，判断"够不够"往往用"多算一点"来保证够。

::: {.problem-card}
**例 1**：每千克苹果 6.5 元，买 3 千克要多少元？

:::

::: {.problem-card}
**例 2**：一袋面粉 45.6 元，买 2 袋，带 100 元够吗？（先估算）

:::

::: {.problem-card}
**例 3**：小汽车每小时行 78.5 千米，3.5 小时行多少千米？

:::

::: {.problem-card}
**练 1**：每本练习本 1.2 元，买 5 本要多少元？

:::

::: {.problem-card}
**练 2**：每米花布 8.4 元，买 2.5 米，带 20 元够吗？

:::

::: {.problem-card}
**练 3**：长方形的长是 4.2 分米，宽是 2.5 分米，面积是多少平方分米？

## 答案 · 一、小数乘整数

::: {.answer-card}
**例 1**：0.5 × 3 表示 **3 个 0.5 相加**，即 0.5 + 0.5 + 0.5 = **1.5**。

:::

::: {.answer-card}
**例 2**：2.6 × 4 = **10.4**。竖式末尾对齐，按 26 × 4 = 104 算，因数有 1 位小数，积点 1 位 → 10.4。

:::

::: {.answer-card}
**例 3**：0.35 × 6，0.35 有 2 位小数，6 是整数有 0 位，积是 **2 位小数**。0.35 × 6 = 2.10 = **2.1**。

:::

::: {.answer-card}
**练 1**：3 × 0.4 表示 **3 个 0.4 相加** = **1.2**。

:::

::: {.answer-card}
**练 2**：1.7 × 3 = **5.1**。

:::

::: {.answer-card}
**练 3**：0.25 × 8 = **2**。（0.25 × 8 = 2.00，去掉末尾 0）

:::

## 答案 · 二、小数乘小数

::: {.answer-card}
**例 1**：2.4 × 0.5，两个因数共 1 + 1 = **2 位小数**，积是 2 位小数。2.4 × 0.5 = 1.20 = **1.2**。

:::

::: {.answer-card}
**例 2**：0.36 × 0.2，共 2 + 1 = **3 位小数**。36 × 2 = 72，积从右往左数 3 位 → 0.072。

:::

::: {.answer-card}
**例 3**：0.15 × 0.4，共 2 + 1 = 3 位小数。15 × 4 = 60，数 3 位 → 0.060，去掉末尾 0 → **0.06**。

:::

::: {.answer-card}
**练 1**：1.2 × 0.7，共 1 + 1 = **2 位小数**。1.2 × 0.7 = 0.84。

:::

::: {.answer-card}
**练 2**：0.5 × 0.24，共 1 + 2 = 3 位小数。5 × 24 = 120，数 3 位 → 0.120，去 0 → **0.12**。

:::

::: {.answer-card}
**练 3**：一个数乘 0.1，相当于把这个数**缩小到原来的十分之一**（小数点向左移动一位）。例如 8 × 0.1 = 0.8。

:::

## 答案 · 三、积的近似数与简便计算

::: {.answer-card}
**例 1**：0.86 × 1.4 = 1.204，保留两位小数看千分位 4，舍去 → **1.20**。

:::

::: {.answer-card}
**例 2**：2.5 × 0.36 × 4 = (2.5 × 4) × 0.36 = 10 × 0.36 = **3.6**。

:::

::: {.answer-card}
**例 3**：0.125 × 4.8 = 0.125 × 8 × 0.6 = 1 × 0.6 = **0.6**。（4.8 拆成 8 × 0.6）

:::

::: {.answer-card}
**练 1**：0.37 × 3.2 = 1.184，保留一位小数看百分位 8，进 1 → **1.2**。

:::

::: {.answer-card}
**练 2**：1.25 × 7.9 × 0.8 = (1.25 × 0.8) × 7.9 = 1 × 7.9 = **7.9**。

:::

::: {.answer-card}
**练 3**：0.4 × 2.5 × 1.3 = (0.4 × 2.5) × 1.3 = 1 × 1.3 = **1.3**。

:::

## 答案 · 四、小数乘法的实际应用

::: {.answer-card}
**例 1**：6.5 × 3 = **19.5 元**。

:::

::: {.answer-card}
**例 2**：45.6 × 2 ≈ 46 × 2 = 92 元 < 100 元，**够**。精确算 45.6 × 2 = 91.2 元，也够。

:::

::: {.answer-card}
**例 3**：78.5 × 3.5 = **274.75 千米**。

:::

::: {.answer-card}
**练 1**：1.2 × 5 = **6 元**。

:::

::: {.answer-card}
**练 2**：8.4 × 2.5 ≈ 8.4 × 2.5 = **21 元** > 20 元，**不够**。（精确算 8.4 × 2.5 = 21，超过 20）

:::

::: {.answer-card}
**练 3**：4.2 × 2.5 = **10.5 平方分米**。

:::
