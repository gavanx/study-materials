## 一、除数是整数的小数除法

**核心思想**：小数除法按整数除法算，**商的小数点要和被除数的小数点对齐**。哪一位不够除，就在这一位上商 0；除到被除数末尾还有余数，就在余数后面添 0 继续除。

::: {.problem-card}
**例 1**：9.6 ÷ 4 等于多少？

:::

::: {.problem-card}
**例 2**：5.7 ÷ 6 等于多少？（注意：整数部分不够除）

:::

::: {.problem-card}
**例 3**：1.8 ÷ 12 等于多少？（余数添 0 继续除）

:::

::: {.problem-card}
**练 1**：8.4 ÷ 7 等于多少？

:::

::: {.problem-card}
**练 2**：3.6 ÷ 9 等于多少？

:::

::: {.problem-card}
**练 3**：0.75 ÷ 5 等于多少？

:::

## 二、除数是小数的小数除法

**核心思想**：除数是小数时，先把**除数和被除数同时扩大相同倍数**，把除数变成整数（移动小数点），再按除数是整数的小数除法算。移动小数点后，被除数的位数可能不够，要补 0。

::: {.problem-card}
**例 1**：7.2 ÷ 0.8 等于多少？（先把除数变成整数）

:::

::: {.problem-card}
**例 2**：2.04 ÷ 0.6 等于多少？

:::

::: {.problem-card}
**例 3**：0.42 ÷ 0.06 等于多少？（被除数位数不够时补 0）

:::

::: {.problem-card}
**练 1**：6.3 ÷ 0.9 等于多少？

:::

::: {.problem-card}
**练 2**：3.6 ÷ 0.12 等于多少？

:::

::: {.problem-card}
**练 3**：一个数除以 0.1，相当于把这个数怎样？

:::

## 三、商的近似数与循环小数

**核心思想**：商的近似数用四舍五入。除不尽时可以先除几位再四舍五入；有些小数商会出现一个或几个数字**依次不断重复**，这叫循环小数，如 1.333… 记作 1.3̇。求近似数时看保留位数的后一位。

::: {.problem-card}
**例 1**：10 ÷ 3 的商是多少？（用循环小数的写法表示）

:::

::: {.problem-card}
**例 2**：2.6 ÷ 0.4 保留一位小数是多少？

:::

::: {.problem-card}
**例 3**：1.5 ÷ 0.7 的商是循环小数吗？把它保留两位小数。

:::

::: {.problem-card}
**练 1**：1 ÷ 6 的商用循环小数怎样表示？

:::

::: {.problem-card}
**练 2**：3.7 ÷ 0.5 保留一位小数是多少？

:::

::: {.problem-card}
**练 3**：判断：2.5 ÷ 8 = 0.3125，商是循环小数吗？

:::

## 四、进一法与去尾法

**核心思想**：实际分东西时，不能只按四舍五入。**进一法**：装不下就要多准备一个容器，如装油、装鸡蛋，结果**无论多小都进 1**；**去尾法**：能做多少就做多少，多余部分舍弃，如做衣服、扎礼品，结果**直接去掉小数部分**。先判断该用哪种方法，再计算。

::: {.problem-card}
**例 1**（进一法）：每个油瓶最多装 2.5 千克油，15 千克油需要几个这样的油瓶？

:::

::: {.problem-card}
**例 2**（去尾法）：一块布料 4.5 米，做一件衣服需要 1.2 米，这块布料最多能做几件？

:::

::: {.problem-card}
**例 3**：一辆车每次运 3.5 吨，12 吨货物需要运几次？

:::

::: {.problem-card}
**练 1**（进一法）：每盒装 0.8 千克饼干，5 千克饼干需要几个盒子？

:::

::: {.problem-card}
**练 2**（去尾法）：一根彩带 6 米，扎一个礼品需要 0.9 米，最多能扎几个？

:::

::: {.problem-card}
**练 3**：每个蛋糕分 0.2 千克，一袋 3 千克的面粉最多能做几个？

:::

## 答案 · 一、除数是整数的小数除法

::: {.answer-card}
**例 1**：9.6 ÷ 4 = **2.4**。（商的小数点和被除数对齐）

:::

::: {.answer-card}
**例 2**：5.7 ÷ 6，整数部分 5 不够除，商 0 点上小数点：5.7 ÷ 6 = **0.95**。

:::

::: {.answer-card}
**例 3**：1.8 ÷ 12，1 不够除商 0，18 ÷ 12 余 6，添 0 变 60 ÷ 12 = 5：1.8 ÷ 12 = **0.15**。

:::

::: {.answer-card}
**练 1**：8.4 ÷ 7 = **1.2**。

:::

::: {.answer-card}
**练 2**：3.6 ÷ 9 = **0.4**。

:::

::: {.answer-card}
**练 3**：0.75 ÷ 5 = **0.15**。

:::

## 答案 · 二、除数是小数的小数除法

::: {.answer-card}
**例 1**：0.8 是一位小数，除数和被除数同时扩大 10 倍：72 ÷ 8 = **9**。

:::

::: {.answer-card}
**例 2**：0.6 是一位小数，同时扩大 10 倍：20.4 ÷ 6 = **3.4**。

:::

::: {.answer-card}
**例 3**：0.06 是两位小数，同时扩大 100 倍：42 ÷ 6 = **7**。（0.42 扩大 100 倍是 42）

:::

::: {.answer-card}
**练 1**：6.3 ÷ 0.9 = 63 ÷ 9 = **7**。

:::

::: {.answer-card}
**练 2**：3.6 ÷ 0.12 = 360 ÷ 12 = **30**。（同时扩大 100 倍）

:::

::: {.answer-card}
**练 3**：一个数除以 0.1，相当于把这个数**扩大 10 倍**（小数点向右移动一位）。例如 0.8 ÷ 0.1 = 8。

:::

## 答案 · 三、商的近似数与循环小数

::: {.answer-card}
**例 1**：10 ÷ 3 = 3.333…，记作 **3.3̇**（3 循环）。

:::

::: {.answer-card}
**例 2**：2.6 ÷ 0.4 = 6.5，保留一位小数就是 **6.5**。

:::

::: {.answer-card}
**例 3**：1.5 ÷ 0.7 = 2.142857142857…，是循环小数。保留两位小数 ≈ **2.14**。

:::

::: {.answer-card}
**练 1**：1 ÷ 6 = 0.1666…，记作 **0.16̇**（6 循环）。

:::

::: {.answer-card}
**练 2**：3.7 ÷ 0.5 = 7.4，保留一位小数就是 **7.4**。

:::

::: {.answer-card}
**练 3**：2.5 ÷ 8 = 0.3125，商**有限小数**，不是循环小数。

:::

## 答案 · 四、进一法与去尾法

::: {.answer-card}
**例 1**：15 ÷ 2.5 = 6 个刚好装完，需要 **6 个**油瓶。（若有余数就进一）

:::

::: {.answer-card}
**例 2**：4.5 ÷ 1.2 = 3.75 件，最多能做 **3 件**（去尾法，余下布料做不完一件）。

:::

::: {.answer-card}
**例 3**：12 ÷ 3.5 = 3.4…次，需要运 **4 次**（进一法，第 4 次运剩下的部分）。

:::

::: {.answer-card}
**练 1**：5 ÷ 0.8 = 6.25，需要 **7 个**盒子（进一法）。

:::

::: {.answer-card}
**练 2**：6 ÷ 0.9 = 6.6…个，最多扎 **6 个**（去尾法）。

:::

::: {.answer-card}
**练 3**：3 ÷ 0.2 = 15，最多做 **15 个**蛋糕。

:::
