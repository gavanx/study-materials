# 方程与不等式 · 拔高

五年级适用，在原版简易方程基础上拔高思维：解稍复杂方程、分数小数系数、列方程解应用题变式、三元换元、不等式整数解、定义新运算与含参方程。

建议每天 5-6 题，做完后让孩子讲一遍思路。

---

## 一、稍复杂方程：去括号与化简

**核心思想**：有括号先按分配律去括号、合并；两边都有 x 时，把 x 并到系数小的一边，避免出现负号；中括号套小括号时由外到内一层层剥。

::: {.problem-card}
**例 1**：3(2x − 1) = 2(x + 3) + 7，求 x。

:::

::: {.problem-card}
**例 2**：2[3(x + 1) − 4] = 22，求 x。

:::

::: {.problem-card}
**练 1**：2(3x − 4) = 3(x + 2) − 8，求 x。

:::

::: {.problem-card}
**练 2**：3(2x + 1) − 2(x − 2) = 15，求 x。

:::

---

## 二、分数与小数系数的方程

**核心思想**：方程里有分数，两边同时乘所有分母的最小公倍数；有小数，乘 10 或合适的数把系数变整数。目的都是把方程化简单。

::: {.problem-card}
**例 3**：x/3 + x/2 = 10，求 x。

:::

::: {.problem-card}
**例 4**：0.5x + 3 = 2x − 6，求 x。

:::

::: {.problem-card}
**练 3**：x/4 + x/6 = 5，求 x。

:::

::: {.problem-card}
**练 4**：1.5x − 4 = 0.5x + 8，求 x。

:::

---

## 三、列方程解应用题：变式拔高

**核心思想**：设未知数时挑"最小的量"设为 x，找同一个量用两种方式表示（盈亏的糖总数、年龄的和），列出等量关系。年龄问题记得两个人一起加年数。

::: {.problem-card}
**例 5**：老师给小朋友分糖果。每人分 3 颗还剩 30 颗；每人分 5 颗还差 18 颗。有几个小朋友？一共有多少颗糖？

:::

::: {.problem-card}
**例 6**：今年父子年龄的和是 60 岁，4 年后父亲的年龄是儿子的 3 倍。今年父子各多少岁？

:::

::: {.problem-card}
**练 5**：两堆苹果，甲堆是乙堆的 3 倍。从甲堆拿出 18 个给乙堆后两堆一样多，原来各多少个？（列方程解）

:::

::: {.problem-card}
**练 6**：蜘蛛有 8 条腿，蜻蜓有 6 条腿。蜘蛛和蜻蜓共 13 只，共有 96 条腿，各有多少只？（列方程解）

:::

## 四、三个未知数的换元

**核心思想**：给的是"两两之和"，把三个式子相加得到"三个数的总和"，再用总和减去不含某个数的两两和，反推每个数。

::: {.problem-card}
**例 7**：已知 A + B = 18，B + C = 24，C + A = 20，求 A、B、C。

:::

::: {.problem-card}
**例 8**：甲、乙、丙三个数，甲 + 乙 = 30，乙 + 丙 = 34，丙 + 甲 = 32，求甲、乙、丙。

:::

::: {.problem-card}
**练 7**：已知 A + B = 15，B + C = 21，C + A = 18，求 A、B、C。

:::

::: {.problem-card}
**练 8**：甲、乙、丙三个数，甲 + 乙 = 40，乙 + 丙 = 46，丙 + 甲 = 42，求甲、乙、丙。

:::

## 五、不等式进阶：整数解与最值

**核心思想**：不等式两边同时加/减同一个数，不等号方向不变；连续不等式（a < bx + c < d）让三个部分同时做同一运算。x 是自然数/整数时，把解集对应到具体数，别漏别重。

::: {.problem-card}
**例 9**：3x − 2 ≥ 4x − 7，x 是自然数，求 x 的所有取值。

:::

::: {.problem-card}
**例 10**：4 < 2x + 3 ≤ 13，x 是整数，求所有 x 的和。

:::

::: {.problem-card}
**练 9**：5x − 3 < 2x + 9，x 是自然数，求 x 的所有取值。

:::

::: {.problem-card}
**练 10**：2 ≤ 3x − 1 < 14，x 是整数，求所有 x 的和。

:::

## 六、定义新运算与含参方程（竞赛档）

**核心思想**：新运算就是按规则代入，嵌套运算从里往外一层层算；含参数的方程，把已知解代进去后，未知数就变成参数 a，照常解方程。

::: {.problem-card}
**例 11**：规定 a△b = a×b − a。若 x△5 = 20，求 x。

:::

::: {.problem-card}
**例 12**：规定 a※b = a + 2b。若 (x※3)※2 = 25，求 x。

:::

::: {.problem-card}
**例 13**：方程 3x + a = 20 的解是 x = 4，求 a。

:::

::: {.problem-card}
**例 14**：方程 ax + 3 = 2x + 15 的解是 x = 4，求 a。

:::

::: {.problem-card}
**练 11**：规定 a□b = 2a + b。若 x□3 = 15，求 x。

:::

::: {.problem-card}
**练 12**：规定 a⊕b = a×b + 1。若 (x⊕2)⊕1 = 16，求 x。

:::

::: {.problem-card}
**练 13**：方程 5x − a = 17 的解是 x = 5，求 a。

:::

::: {.problem-card}
**练 14**：方程 a(x − 1) = 12 的解是 x = 4，求 a。

:::

## 答案 · 一、稍复杂方程：去括号与化简

::: {.answer-card}
**例 1**：去括号：6x − 3 = 2x + 6 + 7 = 2x + 13。两边减去 2x：4x − 3 = 13，4x = 16，**x = 4**。

:::

::: {.answer-card}
**例 2**：由外到内：3(x + 1) − 4 = 11，3x + 3 − 4 = 11，3x = 12，**x = 4**。

:::

::: {.answer-card}
**练 1**：6x − 8 = 3x − 2，3x = 6，**x = 2**。

:::

::: {.answer-card}
**练 2**：6x + 3 − 2x + 4 = 15，4x = 8，**x = 2**。

:::

## 答案 · 三、列方程解应用题：变式拔高

::: {.answer-card}
**例 5**：设小朋友 x 人：3x + 30 = 5x − 18，2x = 48，**24 人**；糖 = 3×24 + 30 = **102 颗**。

:::

::: {.answer-card}
**例 6**：设今年儿子 x 岁，父亲 (60 − x) 岁：64 − x = 3(x + 4)，64 − x = 3x + 12，4x = 52，**儿子 13 岁**，**父亲 47 岁**。

:::

::: {.answer-card}
**练 5**：设乙堆 x 个，甲堆 3x 个：3x − 18 = x + 18，2x = 36，**乙堆 18 个**，**甲堆 54 个**。

:::

::: {.answer-card}
**练 6**：设蜘蛛 x 只，蜻蜓 (13 − x) 只：8x + 6(13 − x) = 96，2x = 18，**蜘蛛 9 只**，**蜻蜓 4 只**。

:::

::: {.answer-card}

:::

## 答案 · 五、不等式进阶：整数解与最值

::: {.answer-card}
**例 9**：两边减 3x：−2 ≥ x − 7，加 7：5 ≥ x，即 x ≤ 5。自然数 **1、2、3、4、5**。

:::

::: {.answer-card}
**例 10**：减 3：1 < 2x ≤ 10，除以 2：0.5 < x ≤ 5。整数 **1、2、3、4、5**，和 = **15**。

:::

::: {.answer-card}
**练 9**：两边减 2x：3x − 3 < 9，3x < 12，x < 4。**x = 1、2、3**。

:::

::: {.answer-card}
**练 10**：加 1：3 ≤ 3x < 15，除以 3：1 ≤ x < 5。**x = 1、2、3、4**，和 = **10**。

:::

## 答案 · 六、定义新运算与含参方程（竞赛档）

::: {.answer-card}
**例 11**：x△5 = 5x − x = 4x = 20，**x = 5**。

:::

::: {.answer-card}
**例 12**：x※3 = x + 6；(x + 6)※2 = x + 6 + 4 = x + 10 = 25，**x = 15**。

:::

::: {.answer-card}
**例 13**：代入 x = 4：12 + a = 20，**a = 8**。

:::

::: {.answer-card}
**例 14**：代入 x = 4：4a + 3 = 8 + 15 = 23，4a = 20，**a = 5**。

:::

::: {.answer-card}
**练 11**：x□3 = 2x + 3 = 15，2x = 12，**x = 6**。

:::

::: {.answer-card}
**练 12**：x⊕2 = 2x + 1；(2x + 1)⊕1 = 2x + 2 = 16，2x = 14，**x = 7**。

:::

::: {.answer-card}
**练 13**：代入 x = 5：25 − a = 17，**a = 8**。

:::

::: {.answer-card}
**练 14**：代入 x = 4：a×3 = 12，**a = 4**。

:::
